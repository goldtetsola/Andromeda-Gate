# Andromeda-Gate Repo Instructions

## Purpose

This repository is a public single-skill package. Optimize for installability,
clarity, and low-friction contribution.

## Structure

- Ship skill content from `skills/andromeda-gate/`
- Keep reference material under `skills/andromeda-gate/references/`
- Keep Claude plugin metadata in `.claude-plugin/`
- Keep OpenAI/Codex skill UI metadata in `skills/andromeda-gate/agents/`
- Keep repo-level contributor docs at the root

## Editing rules

- Keep the public install name, directory name, and frontmatter name aligned as
  `andromeda-gate`
- Prefer moving detail into reference docs instead of letting `SKILL.md` bloat
- Do not leave alternate or deprecated skill copies at the repo root
- Keep `README.md` simple enough for first-time skill users
