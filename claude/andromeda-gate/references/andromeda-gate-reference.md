# Andromeda-Gate Reference

Lookup tables, classification criteria, and checklists for the Andromeda-Gate skill.
Source: Creative Distinctness Cheat Sheet v2 (Cyborg Marketer, February 2026).

---

## 1. Two-Axis Framework

Every creative must be distinct on at least one axis. Best creatives are distinct on both.

| | Same Emotion/Angle | Different Emotion/Angle |
|---|---|---|
| **Looks Different** | PARTIAL — Gets delivery but same audience. Same pond, different wrapper. | BEST — Gets delivery AND reaches new people. This scales. |
| **Looks Similar** | DEAD — Suppressed by algorithm AND same audience. Wasted effort. | WASTED — Smart strategy but Meta won't deliver it. Needs visual overhaul. |

---

## 2. Visual Distinctness Tier System (Axis 1)

Meta's Andromeda system uses AI vision models to scan every ad. Similarity is decided
in the first 1-3 seconds of visual impression. Copy, CTA, and headline are NOT scanned
for similarity — only the visual.

### Tier 1 — Verified Distinct (High Confidence)

Meta-confirmed. These create a genuinely new ad entity.

| Change | Definition |
|--------|-----------|
| New person/talent | Completely different face on screen (or clearly different VO artist) |
| New environment | Different setting — indoor to outdoor, home to gym, studio to casual |
| Format change | Static → video, single image → carousel, video → collection |
| Major framing shift | Product-only → lifestyle, flat-lay → in-use, close-up → full scene |
| Visual medium shift | Photo → illustration, realistic → graphic design, photo → 3D render |

**Minimum:** Every new creative should include at least 1 Tier-1 change.
Two Tier-1 changes = high confidence of distinct entity.

### Tier 2 — Probably Distinct (Medium Confidence)

Weaker signals. Help but unreliable alone.

| Change | Definition |
|--------|-----------|
| First-frame visual | Opening shot is clearly different composition/angle/subject |
| Layout/composition | Vertical → grid, centered → asymmetric, top-down → scattered |
| Color palette overhaul | Warm → cool, muted → vibrant, dark → bright (obvious shifts only) |
| Narrative structure (video) | Reverse order, change tempo, restructure the story arc |
| Audio signature (video) | Different music genre, new VO energy, added silence/ambience |
| Visual density | Minimal → maximalist, clean spacious → information-packed |

**Rule:** If no Tier-1 change is possible, stack 2-3 Tier-2 changes together.

### Tier 3 — Won't Cut It

These do NOT register as distinct to Andromeda. Never rely on alone.

| Change | Why it fails |
|--------|-------------|
| Headline/copy change, same visual | Meta scans visuals, not text |
| Button color swap | Invisible at scroll speed |
| Font or text overlay change only | Not enough visual signal |
| Subtle color grade tweak | A saturation slider isn't a palette overhaul |
| Same person, new outfit | Wardrobe ≠ new talent |
| Same image, different crop | Same visual data |
| Trim without first-frame change (video) | First 3 seconds still match |

## 3. Psychological Distinctness — Three Questions (Axis 2)

For every creative, answer these. If two creatives share the same answers to all three,
they are psychologically identical regardless of visual differences.

| # | Question | What it determines |
|---|----------|-------------------|
| 1 | **Who is this person?** Not demographics — their situation. What's happening in their life that makes this product relevant right now? | Target segment |
| 2 | **What's their itch?** The one thing bothering them. The worry that won't go away, the want they can't shake, the frustration at a specific moment. | Motivation/pain point |
| 3 | **Why would they care about us?** What about this product specifically scratches their itch? Not the general value prop — the specific reason THIS person reaches for it. | Product-to-person connection |

### Example: Same product (sleep supplement), four psychologically distinct ads

| Ad | Who | Itch | Why us |
|----|-----|------|--------|
| A | Stressed professional | Can't switch off after work, lies awake running through tomorrow's to-do list | Helps quiet the mental chatter without sedation |
| B | New parent | Finally gets baby down but can't sleep themselves, needs every hour to count | Fast-acting, non-groggy, safe alongside breastfeeding |
| C | Health-conscious sceptic | Won't take anything "chemical," wants natural ingredients with actual research | Clinically studied natural ingredients, transparent sourcing |
| D | Fitness person | Knows sleep = recovery, optimising everything else but sleep is the bottleneck | Formulated for deep sleep phases that drive muscle recovery |

Four ads, four ponds. Compare: four ads that all say "struggling to sleep?" with four
different creators in four different kitchens = one pond.

## 4. Emotion Map

Eight emotional angles. Each connects to a different group of people. One emotion per ad — never blend.

| Angle | What it sounds like | Who it reaches |
|-------|-------------------|---------------|
| **Fear of loss** | "You're losing [time/money/health] every day you don't fix this." | People in pain right now. Urgent buyers. |
| **Desire for control** | "Take back control of your [sleep/finances/schedule]." | People who feel things are slipping. Want agency. |
| **Social proof / belonging** | "Join 50,000 people who already figured this out." | People who follow trends. Want reassurance. |
| **Aspiration / status** | "The [type of person] you want to be uses [product]." | People buying an identity upgrade. Future-focused. |
| **Curiosity / novelty** | "There's a new approach to [problem] and it's not what you'd expect." | Browsers. Early adopters. Info seekers. |
| **Protection / safety** | "Make sure [bad thing] never happens to you / your family." | Cautious buyers. Prevention-minded. Caregivers. |
| **Frustration / anger** | "Tired of [industry/product] that doesn't work? So were we." | Dissatisfied with alternatives. Ready to switch. |
| **Guilt relief** | "You know you should be doing more about [X]. This makes it easy." | People who already know the problem. Need a nudge. |

**Batch rule:** If all creatives in a batch use the same angle, the batch is
angle-concentrated. Swap at least 2 to different angles.

## 5. Specificity Principle

Generic reaches everyone vaguely. Specific reaches fewer people powerfully — and converts.

| Generic (weak) | Specific (strong) |
|---------------|------------------|
| "Struggling with sleep?" | "It's 2am and you're staring at the ceiling again." |
| "Want better skin?" | "That moment you catch yourself in a Zoom call and barely recognise your own face." |
| "Tired of back pain?" | "That sharp catch when you bend down to tie your shoes and freeze for a second." |
| "Save money on groceries" | "Watching the total climb past £70 for a half-empty trolley." |

Specific moments are one of the strongest tools, but not the only way to be specific.
A concrete number, a surprising claim, or a sharp identity frame can do the same job
depending on the angle. The point is: don't be vague.

**Connection to Axis 2:** Different people experience the same problem at different
moments. Different specific moments = different audiences.

## 6. Feel Understood Rule

Every ad must make the viewer feel understood, not judged. The problem is external —
not their fault. They are not broken, dumb, or lazy.

| Makes them feel judged (wrong) | Makes them feel understood (right) |
|-------------------------------|-----------------------------------|
| "Fix your terrible sleep habits" | "Your brain isn't broken. Modern life just isn't wired for rest." |
| "Stop being lazy about your finances" | "The system's designed to confuse you. That's not your fault." |
| "Your skin looks terrible because you don't take care of it" | "You've tried everything. The problem isn't effort — it's ingredients." |
| "Why haven't you sorted this out yet?" | "Everyone says 'just relax.' Nobody says how." |

**Pattern:** Problem is external. The product helps them keep being who they already
are — it doesn't require them to admit they're failing.

**Why this matters for performance:** When an ad makes someone feel judged, they scroll
past — not because the product isn't relevant, but because buying it would mean
admitting the ad is right about them. Remove the shame, remove the barrier.

## 7. Signal → Action Map

When performance drops, diagnose using both axes.

| Signal | Visual fix (Axis 1) | Angle fix (Axis 2) |
|--------|-------------------|-------------------|
| **CTR dropping** | Swap opening visual entirely. New scene, not just new text. | Current angle might be saturated. Test a completely different emotional trigger. |
| **Hold rate down (video)** | Tighten pacing + add Tier-1 first-frame change. | Emotional hook might not be compelling enough. Try a more specific moment. |
| **CVR dropping** | Add social proof/testimonial. Try a new creator for credibility. | Is the ad making people feel judged? Does it introduce shame? Fix the tone. |
| **CPA rising** | Full visual refresh: new talent + new environment. | You've probably exhausted this angle's audience. Time for a new emotional angle. |
| **Fatigue flagged** | Significant visual change needed. B-roll refresh or model swap. | Same angle, new specific moment. Same worry, different scene from their life. |
| **Broad reach, low engagement** | Too generic visually. Make it more distinctive. | Too broad psychologically. Pick ONE specific person and speak directly to them. |

## 8. SCAMPER Table

Forced-creativity technique. Each letter pushes in a different direction. Use for both axes.

| Letter | Action | Visual ideas (Axis 1) | Angle ideas (Axis 2) |
|--------|--------|----------------------|---------------------|
| **S** | Substitute | Swap model, location, photo for illustration | Swap buyer type. Different life situation entirely. |
| **C** | Combine | Multi-panel layout, before/after split | Merge two benefits for different worries. Layer social proof onto fear. |
| **A** | Adapt | Different demographic, B2C to B2B visual context | Same product, different use case. Morning vs evening. Work vs home. |
| **M** | Modify | Minimal to maximal, dramatic color overhaul, different pacing | Amplify the emotion. Gentle worry → visceral frustration. |
| **P** | Put to use | Same product, totally different setting. Office → weekend. | Reposition around a different moment in their day. |
| **E** | Eliminate | Strip to dead simple, remove all secondary elements | Kill soft sell. Go direct. Or strip to pure emotion, zero product talk. |
| **R** | Reverse | Flip hierarchy: product-first → benefit-first. Outcome → flashback. | Flip emotional frame: "avoid pain" → "imagine how good it could be." |

**Rule:** The bolder the SCAMPER move, the more likely it creates genuine distinctness.
Subtle = Tier-3 territory. Go big.

## 9. Iteration Rules (Change the Wrapper, Keep the Engine)

When iterating a winner, not building a new concept.

### Preserve (the engine)

- The core emotional angle
- How it makes people feel about themselves (understood, not judged)
- The negative-to-positive balance (if the winner leans loss-heavy, keep it)
- The specificity level (if the winner uses a vivid scenario, the iteration needs equal specificity — just a different scenario)
- One clear message (if the winner says one thing well, the iteration says one thing well)

### Change (the wrapper)

- Person on screen / talent
- Setting / environment
- Visual style
- Format
- Opening shot / first frame
- Layout / composition

### When both axes need to shift

If the user wants to target a new audience segment (not just refresh the visual),
that's a new concept — not an iteration. Both the wrapper AND the engine change.
Treat as a fresh build.

## 10. Coverage Grid Template

Map all creatives before launch. Look for spread across columns, not clustering.

| Ad | Who is this person? | What's their itch? | Emotional angle | Visual axis | Distinct? |
|----|--------------------|--------------------|-----------------|-------------|-----------|
| Ad 1 | [situation] | [specific worry/want] | [from emotion map] | [talent, setting, format, palette] | — |
| Ad 2 | [situation] | [specific worry/want] | [from emotion map] | [talent, setting, format, palette] | ✅ or ❌ |
| Ad 3 | ... | ... | ... | ... | ✅ or ❌ |

### Red flags

- **"Who" column looks the same:** All ads targeting same person type → swap 1-2 to different situations
- **"Itch" column looks the same:** All ads hitting same worry → use different emotional trigger
- **"Emotional Angle" column looks the same:** All fear, or all aspiration → mix in other angles
- **"Visual" column looks the same:** Even with different angles, Meta won't deliver → apply tier system

## 11. Briefing Checklist (Pre-Ship Gate)

Every creative must pass ALL checks. Any fail → rework before production.

| # | Axis | Check |
|---|------|-------|
| 1 | Visual | Visual distinctness minimum met? At least 1x Tier-1 OR 2-3x Tier-2 changes. |
| 2 | Visual | Would pass the 1-second scroll test? Colleague would say "different ad." |
| 3 | Visual | SCAMPER action identifiable? You can name which letter(s) applied. |
| 4 | Psych | Different person test passed? A different type of person would care about this than other ads. |
| 5 | Psych | One clear emotion? Commits to one angle, not a blend. |
| 6 | Psych | Specific, not generic? Vivid moment, concrete claim, or sharp identity frame — not a vague problem statement. |
| 7 | Psych | Feel understood, not judged? Problem is external. Viewer is respected. No shame. |
| 8 | Both | Core engine preserved? (iterations only — emotional angle, message structure, tone, specificity intact) |
| 9 | Both | One clear message? The ad says one thing, not three. |

## 12. Quick Decision Trees

### Static creatives

| Ask yourself | If YES | Confidence |
|-------------|--------|------------|
| Can you change the talent/model? | Add new environment too. Ship. | HIGH |
| Can you change the environment? | Add layout or color change. Ship. | MED-HIGH |
| Can you change format or visual medium? | Format jump + 1 Tier-2. Ship. | HIGH |
| None of the above? | Stack 3 Tier-2 changes. Monitor closely. | MEDIUM |

### Video creatives

| Ask yourself | If YES | Confidence |
|-------------|--------|------------|
| New creator/talent? | Add new location. Ship. | HIGH |
| New opening environment? | Kitchen → gym, indoor → outdoor. Add audio change. | MED-HIGH |
| New first 3 seconds visually? | Completely different opening + narrative restructure. | MED-HIGH |
| None of the above? | First-frame + narrative + audio (3x Tier-2). Monitor. | MEDIUM |

These trees handle Axis 1 only. After clearing visual distinctness, check Axis 2
(Section 3's three questions).
